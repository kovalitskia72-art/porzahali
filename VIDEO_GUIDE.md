# Видео в ПОРЖАЛИ

В разделе «Смешное видео» уже есть три оригинальных коротких ролика.

## Быстро добавить свежак
На сайте нажми «Видео» → «Добавить свежак» и вставь ссылку на ролик.
Поддерживаются YouTube, прямые MP4/WebM/Ogg и внешние ссылки.

Пока пользовательские ролики сохраняются в браузере через localStorage. Это удобно для проверки и личной подборки, но такой ролик не становится общим для всех посетителей.

## Общая редакторская лента
Для публикации свежих роликов для всех посетителей нужно подключить постоянное хранилище (например, Supabase). В проекте уже есть `@supabase/supabase-js`, поэтому следующий этап можно сделать без переделки интерфейса: таблица `videos`, редактор добавления/удаления и общая лента.

Не загружай ролики, на которые у проекта нет прав или разрешения на публикацию.
